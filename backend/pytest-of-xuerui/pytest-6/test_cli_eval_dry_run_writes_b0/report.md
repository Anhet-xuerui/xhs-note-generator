# 评测报告：多角色讨论到底值不值

- 主题数 N = 2，三档稿共 6 篇
- 读者 prompt 指纹：`dryrun000000`（改过 prompt 就不再是同一组数据）
- 写作模型：`dry-run-writer`；读者模型：`dry-run-reader`（`dry-run`）

## E1 判别力（construct validity）

同一批三档稿交给读者打分，看它能不能把 good / mid / bad 排对。

| 指标 | 值 | 判据 |
|---|---|---|
| 排序正确率 | 50% | ≥ 80% 有判别力 |
| Kendall τ | 0.33 | 越接近 1 越好 |
| 权重 ×0.7 下的正确率 | 50% | 敏感性检查 |
| 权重 ×1.0 下的正确率 | 50% | 敏感性检查 |
| 权重 ×1.3 下的正确率 | 50% | 敏感性检查 |

- **判别力 ≥ 80%**：未达成
- **权重 ±30% 结论稳定**：达成

## E2 双厂商一致性（reliability）

| 指标 | 值 | 判据 |
|---|---|---|
| click 的 Cohen κ | 0.40 | ≥ 0.6 可接受 |
| save 的 Cohen κ | — | ≥ 0.6 可接受 |
| score 的 Spearman ρ | 0.60 | 越接近 1 越好 |

- **两家厂商判定一致（κ ≥ 0.6）**：未达成

## E3 消融（A 裸模型 / B 七角色 / C 同厂商读者）

| 组 | 配置 | 通过率 | 平均分 | tokens | 成本(元) | 时延(s) | 平均 AI 味 |
|---|---|---|---|---|---|---|---|
| A | 裸模型单次成稿 | 0% | 1.20 | 1200 | 0.01 | 5.0 | 40.0 |
| B | 完整链路 | 50% | 3.40 | 8000 | 0.06 | 70.0 | 12.0 |
| C | 完整链路 + 读者同厂商 | 50% | 3.40 | 8000 | 0.06 | 68.0 | 12.0 |

> 评分口径：三组成稿都由**同一个读者实例**事后打分；A 组的评分调用成本单列在它的 tokens/成本里。

## 局限

- 没有真实互动数据：判定器的有效性只有内部验证（判别力 + 一致性），不能证明它等同于真实用户。
- `bad` 档是反向 prompt 构造的，它定义的是「我们能想到的 AI 味」，不是全部。
- 标签级、选题级的效果没有验证；本轮也没有人工盲评（E4）。
- 规模缩小后统计量噪声变大，报告里的 N 就是实际样本数，不要外推。

## 备注

- 这是 dry-run 的合成数据，不代表任何真实结论。
