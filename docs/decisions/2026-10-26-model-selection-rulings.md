# D11 模型可配：裁决记录

日期：2026-10-26
对应设计：`docs/superpowers/specs/2026-10-26-per-role-models-design.md`

---

## 1. 取消「读者必须与主笔不同模型」的启动拦截，改成打标

**怎么定的**：`Settings.load()` 不再拒绝同 provider 同模型；每次 run 的 `ModelSet` 记 `reader_independent`，界面与报告在 false 时显式写「读者=主笔：非独立评审」。

**为什么**：用户要自由选模型（包括让读者和主笔一样）。但 E2 的 κ、E3 的「A 胜率上界 36%」都建立在「读者不是作者本人」上——悄悄允许等于让那批数字变成假的。打标是唯一能同时满足「自由」与「能自证」的做法。

**代价**：`docs/samples/` 的数字只对独立评审的 run 成立；读报告的人必须看见那行标记，否则会误引。

---

## 2. 未登记价格的模型也能跑，成本显示「≥」

**怎么定的**：`LLMClient._apply_cost` 命中 `PRICES` 才算钱；未命中只累计 `unpriced_calls`。报告与界面写 `≥ x 元（N 次未计价）`。

**为什么**：原设计用 `UnknownModelPrice` 在开跑前直接拒绝。但 19 个模型里只有 4 个有价格，拒绝会让「换模型」这个功能对 15 个模型失效。token 是硬账，钱只要不写 0 就不算撒谎。

**代价**：`cost_cny` 从此是**下界**。任何引用成本的地方都必须带「≥」与未计价次数，否则数字仍然会骗人。

---

## 3. 评测仍固定用 `.env` 的默认模型

**怎么定的**：`cli eval` 的 `Deps` 显式注入 `ModelSet.defaults(default_models(settings))`；有覆盖时启动打印一行警告。

**为什么**：与 prompt 同一条理由——量具不能跟着被测对象变。否则界面上换个模型，`docs/samples/` 的对照就断了。

**代价**：评测与界面跑的不是同一套模型；这一点靠启动警告让人看见。
