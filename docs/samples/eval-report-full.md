# 评测报告：多角色讨论到底值不值

- 主题数 N = 10，三档稿共 21 篇
- 读者 prompt 指纹：`e069792cc49b`（改过 prompt 就不再是同一组数据）
- 写作模型：`deepseek-v4.1-flash`；读者模型：`glm-5.3-flash`（`127.0.0.1:8788`）

## E1 判别力（construct validity）

同一批三档稿交给读者打分，看它能不能把 good / mid / bad 排对。

| 指标 | 值 | 判据 |
|---|---|---|
| 排序正确率 | 29% | ≥ 80% 有判别力 |
| Kendall τ | 0.60 | 越接近 1 越好 |
| 权重 ×0.7 下的正确率 | 29% | 敏感性检查 |
| 权重 ×1.0 下的正确率 | 29% | 敏感性检查 |
| 权重 ×1.3 下的正确率 | 29% | 敏感性检查 |

- **判别力 ≥ 80%**：未达成
- **权重 ±30% 结论稳定**：达成

## E2 双厂商一致性（reliability）

| 指标 | 值 | 判据 |
|---|---|---|
| click 的 Cohen κ | 0.83 | ≥ 0.6 可接受 |
| save 的 Cohen κ | 0.41 | ≥ 0.6 可接受 |
| score 的 Spearman ρ | 0.77 | 越接近 1 越好 |

- **两家厂商判定一致（click 与 save 的 κ 都 ≥ 0.6）**：未达成

## E3 消融（A 裸模型 / B 七角色 / C 同厂商读者）

| 组 | 配置 | 通过率 | 平均分 | tokens | 成本(元) | 时延(s) | 平均 AI 味 |
|---|---|---|---|---|---|---|---|
| A | 裸模型单次成稿 | 0% | 7.65 | 24416 | 0.1037 | 97.3 | 7.6 |
| B | 完整链路 | 38% | 8.75 | 115550 | 0.4655 | 411.8 | 4.4 |
| C | 完整链路 + 读者同厂商 | 43% | 9.07 | 128693 | 0.5081 | 396.8 | 13.3 |

> 评分口径：三组成稿都由**同一个读者实例**事后打分；A 组的评分调用成本单列在它的 tokens/成本里。

## 局限

- 没有真实互动数据：判定器的有效性只有内部验证（判别力 + 一致性），不能证明它等同于真实用户。
- `bad` 档是反向 prompt 构造的，它定义的是「我们能想到的 AI 味」，不是全部。
- 标签级、选题级的效果没有验证；本轮也没有人工盲评（E4）。
- 规模缩小后统计量噪声变大，报告里的 N 就是实际样本数，不要外推。
