## E1 判别力（construct validity）

| 指标 | 值 | 判据 |
|---|---|---|
| 排序正确率 | 50% | ≥ 80% 有判别力 |
| Kendall τ | 0.63 | 越接近 1 越好 |
| 权重 ×0.7 下的正确率 | 50% | 敏感性检查 |
| 权重 ×1.0 下的正确率 | 50% | 敏感性检查 |
| 权重 ×1.3 下的正确率 | 50% | 敏感性检查 |
| **两两比较正确率** | 95%（24 次比较，位置不一致 21%） | ≥ 80% 有判别力 |

- **权重 ±30% 结论稳定**：达成
- **两两比较判别力 ≥ 80%**：达成

## 局限

- 没有真实互动数据：判定器的有效性只有内部验证（判别力 + 一致性），不能证明它等同于真实用户。
- `bad` 档是反向 prompt 构造的，它定义的是「我们能想到的 AI 味」，不是全部。
- 标签级、选题级的效果没有验证；本轮也没有人工盲评（E4）。
- 规模缩小后统计量噪声变大，报告里的 N 就是实际样本数，不要外推。
